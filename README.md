# 🏨 Danholt Suites - Luxury Hotel Website

## About
Complete hotel website with booking system. Migrated from Base44 to independent Next.js application with Supabase backend.

## Features
- 🏠 Beautiful landing page with animations
- 🛏️ Room listings and detailed views
- 📅 Room booking system
- 🍽️ Restaurant menu and table reservations  
- 🏋️ Facilities showcase and booking
- 📱 Fully responsive design
- ⚡ Fast and modern (Next.js 14)

## Tech Stack
- **Frontend:** Next.js 14, React, Tailwind CSS
- **Animations:** Framer Motion
- **UI Components:** Radix UI, shadcn/ui
- **Backend:** Supabase (PostgreSQL)
- **Deployment:** Vercel

## Quick Setup

```bash
# Install dependencies
npm install

# Set up environment variables
# Create .env.local file with:
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key

# Run development server
npm run dev
```
